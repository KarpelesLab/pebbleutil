# pebbleutil

Some small tools useful when interacting with pebble dbs

This is the `v2` line, built against [`cockroachdb/pebble/v2`](https://github.com/cockroachdb/pebble).

```
go get github.com/KarpelesLab/pebbleutil/v2
```

The `v1` line (for `cockroachdb/pebble` v1) lives on the `master` branch.
